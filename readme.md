\# My Simple Website



A clean, responsive starter website built using vanilla \*\*HTML\*\*, \*\*CSS\*\*, and \*\*JavaScript\*\*. It features a centered card layout and an interactive button click counter.



\## Project Structure



```text

my-website/

├── index.html   # Main webpage structure and content

├── style.css    # Layout, styling, and responsive design

├── script.js    # Interactive button counter logic

└── README.md    # Project documentation

```



\## Features



\* \*\*Clean Layout:\*\* Responsive flexbox layout that centers content vertically and horizontally.

\* \*\*Interactive Counter:\*\* Uses JavaScript DOM manipulation to track and display button clicks in real time.

\* \*\*Zero Dependencies:\*\* Runs directly in any modern web browser without frameworks or build tools.



\## How to Run Locally



1\. Download or clone this project folder to your computer.

2\. Open the `my-website` folder.

3\. Double-click \*\*`index.html`\*\* to launch the site in your default web browser.



\## Customization



\* \*\*Change Website Title:\*\* Edit the `<title>` tag inside `index.html`.

\* \*\*Change Colors:\*\* Update the hex color codes (such as `#2563eb`) inside `style.css`.

\* \*\*Add Features:\*\* Expand `script.js` to add new interactive elements.
